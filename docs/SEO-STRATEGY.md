# ビズフォーム SEO戦略

キーワード戦略の正本。出典は Google Keyword Planner（2025-09-01〜2026-08-31 / 日本 / Google）と
現行サイト構成をもとにした `BizForm_SEO_strategy_for_AI_agent_20260920.csv`。

## 全体方針

1. **拡張順序**: ①フォーム営業の今すぐ客 → ②比較・代替市場 → ③新規開拓・リード獲得などの上流市場。
   検索ボリュームの大きさではなく、**BizFormとの適合度と購入意向**を優先する。
2. **1検索意図＝1URL**。同じ主キーワードを複数ページで競わせない（カニバリ防止）。
   canonical で主担当URLを明示している。
3. **新規記事の量産より既存ページの強化を先に**。すでに検索意図に近いページがあるため。
4. **デザインは変更しない**。SEO変更は title / meta / H1補助文 / 本文 / 内部リンクに限定する。
5. **AI検索対策専用の薄い記事は作らない**。各ページを
   「結論 → 比較表 → 向く/向かない → 料金・工数 → 実例 → FAQ → 出典」で構造化する。
6. **「営業代行」（月5,400）をTOPの主KWにしない**。BizFormは商談・提案・クロージングを
   行う総合営業代行ではないため、誤認訴求になる。比較記事から誘導する。
7. **検索数が「—」でも購入直前意図（料金・相場・比較・契約条件）は残す**。0検索として扱わない。
8. Google広告の「競合性」はSEO難易度ではない。CPCは商業価値の補助指標としてのみ使う。

## 書くときの禁止事項

- **総合営業代行と誤認させない**。商談・提案・クロージングは依頼企業が担当する。
- **「完全AI自動化」「100%自動」**など、実際の運用以上の表現をしない。
- **料金は推測で書かない**。競合の公開価格のみを、出典URLと更新日を添えて使う。
- **法的助言を断定しない**（「必ず合法」等を書かない）。必要なら公的情報へリンクする。
- **他社の数字を出典なしに平均値として断定しない**。数値には期間・母数・定義を添える。
- **業種名・地域名だけを変えた類似ページを作らない**（`CONTENT-RULES.md` と同じ方針）。

## 技術的な土台（2026-09-20 実施）

- **canonical**: 全19ページに設置。sitemap.xml と完全一致。1検索意図1URLの土台。
- **OG / Twitter カード**: 全19ページ。title・description から自動生成している。
- **構造化データ**:
  - TOP … `Organization` + `Service`（対応工程を `hasOfferCatalog` で明示）
  - `/faq/` … `FAQPage`（JSON-LD、25問。ページ内のmicrodataから生成し二重管理を避ける）
  - 下層13ページ … `BreadcrumbList`（既存のパンくずHTMLから生成）
- **内部リンク**: ガイド記事末尾に `.next-read`（「あわせて読みたい」）を設置。
  リンクには必ず**遷移する理由**を1行添える。リンク列挙だけにしない。
